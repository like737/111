📖 使用说明 / 已知限制

  1. 只勾选 + 点【开始拦截】即可：不需要去别的控制台、不需要重启服务，改完立刻生效 （guard 每次判定都重新读配置）。
  2. HTTPS 的显示效果：走代理时 HTTPS 命中只能显示浏览器自己的错误页 （ERR_TUNNEL_CONNECTION_FAILED），这是不装根证书的物理限制； 想连 HTTPS 也看到漂亮拦截页，请在浏览器里装 guard 的油猴脚本 （guard\userscript\eyilianjie_guard.user.js）。
  3. 点【停止拦截】会还原你的代理设置：guard 开启前会记录原值（例如你自己的 127.0.0.1:10808），停止时逐项还原，不会顶掉你的科学上网工具。
